# How this file works
# - Each section below is one kind of sentence the page says at ages 6–8.
# - Write your sentence on the line after "6-8:". Leave it empty and the page keeps
#   using the 9–11 sentence shown above it, so you can fill this in a bit at a time.
# - Words in {curly brackets} are blanks the page fills in from Ani's own record of
#   the film. Use any of the blanks listed for that section, in any order, or leave
#   some out. Don't invent new ones; ask and they can be added.
# - Lines starting with # are notes and are ignored. Save the file; the next build
#   puts your sentences into the page. No HTML to edit.
# - The examples use a made-up story, "The Kite", so they don't repeat Cinderella:
#     Pip (the blue circle) is shy. Tam (the yellow triangle) is helpful towards Pip.
#     In the last scene Tam gives Pip a kite, and Pip becomes happy.
# - At 6–8 the page names characters by shape and color ("the blue circle"); the
#   name is shown beside the picture. So {who} below will be "the blue circle".
#
# Blanks that work everywhere:
#   {who}    the character, e.g. "the blue circle"
#   {Who}    the same with a capital letter, to start a sentence
#   {is}     "is" or "are", agreeing with {who}
#   {seconds}  a time, e.g. "2.5 seconds"
