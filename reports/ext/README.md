# What the revival's extensions make of Ken's Cinderella

The extensions that leave Ken's Cinderella as it was (MEND) are checked against the 1978 goldens themselves, by `node tools/check-1978.mjs --extensions mend`. Those that are meant to change it each have a folder here, with the files a run makes and a README that explains each difference from 1978. `tools/check-ext.mjs` checks them.

- [appear/](appear/README.md): Ani chooses her characters' sizes and shapes (Phase 9, stage 2), at 4 frames a second and, in `appear/24fps/`, at 24. `npm run test:ext` and `npm run test:ext24`.
- [know/](know/README.md): the knowledge you could have added (Phase 9, stage 4): words, ways of showing relationships, three display methods, feelings, and a word borrowing its neighbors' ways of showing itself. Pass 1 is as in 1978, byte for byte; in pass 2 Cinderella follows her stepmother and helps the Prince in the Introduction, and the stepmother's pride cancels her joy's speeding up in Kept Apart. At 4 frames a second and, in `know/24fps/`, at 24. `npm run test:know` and `npm run test:know24`.
- [change/](change/README.md): characters who change (Phase 9, stage 3). CHANGE leaves Ken's Cinderella as it was (`node tools/check-1978.mjs --extensions change`); its folder has the fresh looks at a repentant stepmother, a Cinderella who stops being shy and Ken's beautified Cinderella, and two stories made end to end. `npm run test:change`.
